# Badge Github Actions Pkgdown

Badge Github Actions Pkgdown

## Usage

``` r
use_badge_ghactions_pkgdown(repo = NULL, user = "KWB-R", branch = NULL)
```

## Arguments

- repo:

  name of repository (default: NULL)

- user:

  user name or organisation under which repository defined in parameter
  "repo" is hosted (default: "KWB-R")

- branch:

  default: NULL (i.e. use "default" branch) or user defined branch (e.g.
  "dev")

## Value

generates Github Actions Pkgdown badge link
