# Badge R-Universe

Badge R-Universe

## Usage

``` r
use_badge_runiverse(repo = NULL, user = "KWB-R")
```

## Arguments

- repo:

  name of repository (default: NULL)

- user:

  user name or organisation under which repository defined in parameter
  "repo" is hosted (default: "KWB-R")

## Value

generates R-Universe badge markdown
