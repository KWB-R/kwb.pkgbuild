# Git Check Configuration

Git Check Configuration

## Usage

``` r
git_check_config(git_exe = path_to_git())
```

## Arguments

- git_exe:

  path to git executable on Windows (default: path_to_git())

## Value

prints 'global' and 'local' Git configuration

## Examples

``` r
if (FALSE) { # \dontrun{
git_check_config()
} # }
```
