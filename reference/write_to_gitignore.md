# Write to .gitignore

Write to .gitignore

## Usage

``` r
write_to_gitignore(ignore_pattern, comment = NULL)
```

## Arguments

- ignore_pattern:

  pattern that should be added to .Rbuildignore

- comment:

  optional comment to write to file before the ignore pattern \#'
  (default: NULL)

## Value

.gitignore created/updated with pattern
